# Tutorials

Tutorials combine multiple Mongoz owners into end-to-end flows:

- [CRUD application](crud.md) builds a complete modeled read/write boundary.
- [Multiple databases and indexes](multiple-databases-indexes.md) adds database selection and safe reconciliation.
- [Aggregation and bulk writes](aggregation-bulk.md) enters trusted native MongoDB structures.
- [Sessions and transactions](sessions-transactions.md) propagates one PyMongo session correctly.
- [Production setup](production.md) connects lifecycle, configuration, startup checks, and shutdown.

Run the examples against a disposable database before adapting them. Transaction examples need a
replica set or sharded cluster.
