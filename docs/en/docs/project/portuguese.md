# Portuguese documentation

The Portuguese manual is archived. Its historical pages had fallen materially behind the English
runtime contracts, including the PyMongo Async migration, Registry lifecycle, persistence and index
safety, sessions, signals, security, and production guidance. Presenting that content as current
would be more harmful than a smaller honest support surface.

Existing `/pt/...` URLs remain available as compatibility pages. Each page states that it is
archived and links to the current English owner. They are not a second editable technical source and
do not claim translation parity.

The project may restore maintained Portuguese documentation in the future only with an explicit
translation owner, parity checks, current navigation, and the same strict build and example
standards as English.

Use the [English introduction](../start/introduction.md) for current documentation.
