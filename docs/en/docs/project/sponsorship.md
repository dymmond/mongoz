# Sponsorship

Mongoz is open-source software maintained alongside a wider Python ecosystem. If it supports your
work, you can sponsor the maintainer through [GitHub Sponsors](https://github.com/sponsors/tarsil).

Sponsorship does not replace issue reports, reproducible tests, documentation fixes, or careful code
review. Those contributions remain welcome through the
[Mongoz repository](https://github.com/dymmond/mongoz).
